# GitHubSecurityDemo
Мова програмування: C#
Платформа: .NET

Цей проєкт написаний мовою C# на платформі .NET і призначений для демонстрації безпечної роботи з GitHub.

Мета демонстрації:
- SSH доступ до GitHub
- GPG підпис комітів
- Захист секретів через `.gitignore` та `pre-commit`
- Пошук вразливостей через Sonar

Як запустити:
1. Відкрийте термінал у папці проєкту `GitHubSecurityDemo`.
2. Запустіть команду:

```bash
dotnet run
```

Не додавайте реальні секрети до проєкту. Використовуйте `.env.example` як приклад.

Підсумок:
- Проєкт реалізовано саме на C# .NET.
- Інтерфейс і повідомлення в програмі доступні українською мовою.
- Конфігурація `pre-commit` налаштована для перевірки секретів.
