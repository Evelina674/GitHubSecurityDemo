# GitHubSecurityDemo
Мова програмування: C#
Платформа: .NET

Цей проєкт написаний мовою C# на платформі .NET і призначений для демонстрації безпечної роботи з GitHub.

Мета демонстрації:
- SSH доступ до GitHub
- GPG підпис комітів
- Захист секретів через `.gitignore` та `pre-commit`
- Пошук вразливостей через Sonar

Як запустити:
1. Відкрийте термінал у папці проєкту `GitHubSecurityDemo`.
2. Запустіть команду:

```bash
dotnet run
```

Не додавайте реальні секрети до проєкту. Використовуйте `.env.example` як приклад.

Підсумок:
- Проєкт реалізовано саме на C# .NET.
- Інтерфейс і повідомлення в програмі доступні українською мовою.
- Конфігурація `pre-commit` налаштована для перевірки секретів.

## Мета проєкту

GitHubSecurityDemo — навчальний C#/.NET проєкт, створений для демонстрації безпечної роботи з GitHub. Проєкт показує використання SSH, GPG-підпису комітів, перевірки секретів за допомогою pre-commit та статичного аналізу коду.

## Швидкий старт

1. Клонуйте репозиторій:
   `git clone git@github.com:Evelina674/GitHubSecurityDemo.git`

2. Перейдіть до папки проєкту:
   `cd GitHubSecurityDemo`

3. Відновіть залежності:
   `dotnet restore`

4. Зберіть проєкт:
   `dotnet build`

5. Запустіть програму:
   `dotnet run`

## Приклад використання

Після запуску програми користувач може перевірити роботу навчального C# застосунку, а структура репозиторію демонструє використання інструментів безпеки GitHub.

Перед створенням коміту можна запустити перевірку:

`python -m pre_commit run --all-files`

Це дозволяє перевірити файли проєкту на наявність випадково доданих секретів.
