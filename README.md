# GitHubSecurityDemo

Цей простий проєкт створено для демонстрації налаштування безпечного доступу в GitHub.

Мета демонстрації:
- SSH доступ до GitHub
- GPG підпис комітів
- Захист секретів через `.gitignore` та `pre-commit`
- Пошук вразливостей через Sonar

Як запустити:
1. Відкройте термінал у папці проєкту `GitHubSecurityDemo`.
2. Запустіть:

```
 dotnet run
```

Не додавайте реальні секрети у проєкт. Використовуйте `.env.example` як приклад.
