# Contributing

Дякуємо за інтерес до проєкту GitHubSecurityDemo!

## Як зробити внесок

1. Створіть окрему гілку для своїх змін:
   `git checkout -b feature/my-feature`

2. Внесіть необхідні зміни до проєкту.

3. Перед відправленням змін перевірте, що проєкт успішно збирається:
   `dotnet build`

4. Переконайтеся, що тести та перевірки безпеки проходять успішно.

5. Збережіть зміни за допомогою Git:
   `git add .`
   `git commit -m "Describe your changes"`

6. Відправте гілку на GitHub:
   `git push origin feature/my-feature`

7. Створіть Pull Request до гілки `main`.

## Вимоги до Pull Request

- Коротко опишіть внесені зміни.
- Один Pull Request повинен стосуватися однієї задачі.
- Код повинен успішно збиратися.
- Не додавайте паролі, API-ключі або інші конфіденційні дані.
- Дотримуйтеся правил, зазначених у CODE_OF_CONDUCT.md.
