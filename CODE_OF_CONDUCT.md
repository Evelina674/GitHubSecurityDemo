# Code of Conduct

## Наші принципи

Ми прагнемо створити доброзичливе, безпечне та професійне середовище для всіх учасників проєкту.

Учасники повинні:

- поважати інших розробників;
- спілкуватися ввічливо та конструктивно;
- уникати образ, дискримінації та агресивної поведінки;
- приймати обґрунтовану критику;
- дотримуватися професійної етики;
- поважати приватність та особисті дані інших користувачів.

## Неприйнятна поведінка

Не допускаються:

- образи та приниження;
- дискримінація за будь-якими ознаками;
- погрози або переслідування;
- публікація чужої приватної інформації без дозволу;
- навмисне створення конфліктів;
- спам та інша деструктивна поведінка.

## Відповідальність

Учасники, які порушують правила, можуть отримати попередження або бути відсторонені від участі у проєкті.

Усі учасники повинні сприяти взаємоповазі, безпечному спілкуванню та конструктивній співпраці.
